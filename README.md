# rassvet detail

Учебный интернет-магазин украшений.
Лабораторная работа по веб-программированию.

## Технологии

- HTML
- CSS
- JavaScript

CSS- и JavaScript-фреймворки не используются.

## Планируемые возможности

- Просмотр каталога товаров.
- Добавление товаров в корзину.
- Удаление товаров и изменение их количества.
- Автоматический пересчёт итоговой суммы.
- Сохранение корзины в localStorage.
- Оформление учебного заказа.
- Адаптивное отображение на разных устройствах.

## Структура проекта

- index.html — разметка страницы.
- css/style.css — стили.
- js/data.js — данные товаров.
- js/app.js — логика магазина.
- images/ — изображения и favicon.
- fonts/ — локальные шрифты.

## Запуск

Открыть папку проекта в VS Code.
Запустить index.html через расширение Live Server.
