# Лабораторная 1 (Web-программирование) - rassvet detail

_Короткова Алиса Александровна, 466293, поток Web 3.1_

Учебный интернет-магазин украшений - о любви на языке украшений.
Проект выполнен в рамках лабораторной работы 1 по веб-программированию.

[Открыть сайт](https://alisakorotkova.github.io/web-prog_sem1-lab1/)

## Возможности

- Каталог из восьми украшений.
- Добавление и удаление товаров, изменение количества в корзине.
- Автоматический пересчет суммы и сохранение корзины в localStorage.
- Форма заказа с проверкой обязательных полей и телефона.
- Адаптивная вёрстка для компьютеров, планшетов и смартфонов.

## Технологии

HTML, CSS и JavaScript без фреймворков.
Для вёрстки используются Flexbox, Grid и медиазапросы.

## Структура проекта

- `index.html` - разметка страницы.
- `css/style.css` - оформление и адаптивность.
- `js/data.js` - данные товаров.
- `js/app.js` - каталог, корзина и оформление заказа.
- `images/` - фотографии.
- `fonts/` - локальные шрифты Manrope и Gill Sans.

## Локальный запуск

Откройте папку проекта в VS Code и запустите `index.html`
через расширение Live Server.
